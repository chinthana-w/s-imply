# ITC99 10,000-Fault Set Composition

## Overview

This document describes the composition of
`data/bench/ITC99_all_numeric/fault_pool_10000_seed20260713.json`.
The set contains 10,000 single stuck-at faults drawn from 21 normalized,
full-scan ITC99 benchmark circuits.

In the stored five-valued-logic encoding, `fault_val = 3` represents a
stuck-at-0 fault and `fault_val = 4` represents a stuck-at-1 fault.

## Selection method

The pool was generated by
`scripts/select_itc99_multicircuit_fault_pool.py` using equal allocation with
capacity-aware redistribution:

1. Enumerate both stuck-at polarities for every eligible gate in every
   normalized circuit.
2. Allocate the 10,000-fault budget as evenly as possible across all circuits.
3. Include a circuit's entire population when it contains fewer faults than its
   equal share.
4. Redistribute the unused capacity among the remaining circuits.
5. Select each non-exhaustive circuit's faults with deterministic random
   sampling using seed `20260713`.

This policy emphasizes circuit balance rather than sampling in proportion to
circuit size. Consequently, every large circuit contributes exactly 596 faults,
while the seven smallest circuits are represented exhaustively. It also yields
an almost even polarity split without imposing a separate SA-0/SA-1 quota.

## Scope notes

- The source benches are under `data/bench/ITC99_all_numeric/` and are numeric,
  normalized full-scan versions of the ITC99 circuits.
- The set includes `b15_1`, the normalized benchmark name used in this corpus.
- There is no `b16` entry in this corpus, so it is not part of the fault set.
- `pool_index` values run from 0 through 9,999. Within each circuit, selected
  source indices are sorted after random sampling, and circuits appear in bench
  filename order.
